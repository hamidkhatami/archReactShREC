# CSR-frontend
ui عملیات تسویه و مغایرت گیری شتاب و شاپرک  

## ویژگی‌ها

- **React 18** و **TypeScript 5**  
- مدیریت **state** با **Zustand**  
- مدیریت درخواست‌های **API** با **Axios** و **React Query**  
- پشتیبانی از **چند زبان (i18n)** با **react-i18next** و **i18next**  
- رابط کاربری با **Material UI 5** و آیکون‌ها  
- **Date Picker** شمسی و چندگانه با **react-multi-date-picker**  
- RTL / LTR با **stylis-plugin-rtl**  
- تست واحد با **Vitest** و **Testing Library**  

## پیش‌نیازها

- Node.js >= 18  
- Yarn یا npm  

## نصب

```bash
# کلون کردن مخزن
git clone [آدرس مخزن شما]

# ورود به پوشه پروژه
cd [نام پوشه پروژه]

# نصب وابستگی‌ها
yarn install
# یا با npm
npm install


# اجرای پروژه در حالت توسعه
yarn dev
# یا با npm
npm run dev

# ساخت پروژه برای تولید
yarn build
# یا با npm
npm run build

# پیش‌نمایش نسخه build شده
yarn preview
# یا با npm
npm run preview

# اجرای تست‌ها با Vitest
yarn test
# یا با npm
npm run test

# بررسی کد با ESLint
yarn lint
# یا با npm
npm run lint
